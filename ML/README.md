# Прогнозування ціни автомобіля

Модель лінійної регресії прогнозує ціну автомобіля за роком випуску,
об'ємом двигуна, пробігом, потужністю, маркою (`brand`) і моделлю (`model`).
Числові ознаки передаються до моделі напряму, а `brand` і `model` кодуються
за допомогою `OneHotEncoder`.

## Запуск

З кореневої папки проєкту встановіть залежності та запустіть скрипт:

```powershell
python -m pip install -r ML/requirements.txt
python ML/train_car_price.py
```

Скрипт читає `assets/cars.csv`, випадково відокремлює 20% даних для
тестування та навчає модель на решті 80%. Якщо CSV не містить ані `brand`,
ані `model`, скрипт створює демонстраційні категорії та симульовані цінові
надбавки для них і записує похідний набір у
`ML/cars_with_brand_model.csv`. Ці надбавки — лише приклад, а не ринкові
дані. Якщо вхідний CSV містить обидва стовпці, модель використає наявні
значення без симуляції; наявність лише одного з них вважається помилкою.

Виводяться MAE, R² і MAPE — середня абсолютна відносна помилка у відсотках.
Менше значення MAPE означає меншу середню помилку прогнозу.

Графік порівняння справжніх і прогнозованих цін зберігається у
`ML/actual_vs_predicted.png`. Чим ближче точки до пунктирної діагоналі,
тим точніші прогнози.
